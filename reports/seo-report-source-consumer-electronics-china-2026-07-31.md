## 4. 战略改进（需要更多时间）

### 4.1 单一 URL 的锚文本过度集中 - 中度风险

`products/consumer-electronics.html` 被链接 **7 次**，锚文本为：
`china electronics manufacturer` / `consumer electronics wholesale china` / `shenzhen electronics market` / `china electronics manufacturer`（重复）/ `import electronics from china` / `electronics sourcing agent china` / `consumer electronics we source`

**7 条中 6 条是精确匹配商业关键词锚文本，指向同一个商业页面。** 这是站内锚文本轰炸的典型形态。虽然是内链（风险远低于外链），但对一篇 3,572 词的文章而言，同一 URL 7 次链接本身就超出正常密度，且锚文本几乎清一色是关键词而非自然语言。

**建议：** 削减到 4-5 条，保留转化价值最高的 3 个位置（H2 02 表格下 CTA slot 1、H2 07、H2 13 CTA），其余 2-3 条改为无链接的纯文本提及，或分流到 `products/bluetooth-earbuds-tws.html`、`products/gps-tracker-smart-tag.html` 等具体 SKU 页（这些页在价格表里已经以 code 形式列出但**没有做成链接** - 这是一个被浪费的内链与转化机会）。
