## 0. 方向可行性判断（回答 Karsa 的核心问题）

### "这个方向值得做吗？"

**回答：值得，而且有一个竞争对手集体忽视的突破口。**

分析了排名前 5 的同类文章（Maple Sourcing、Owl Sourcing、Best Sourcing Agent、SourcingAll、SFA Commercial），发现一个一致的模式：**所有竞争对手都在写"费用结构科普"，但没有一个人敢公布自己的实际收费。**

| 竞争对手 | 写了什么 | 没写什么 |
|----------|----------|----------|
| Maple Sourcing | 3 种收费模式、5 个成本桶、小订单$150-$450 | 自己公司的实际收费、真实案例计算 |
| Owl Sourcing | 5-10% 佣金、假设性案例$26,200 | 自己到底收多少、最低合作金额 |
| Best Sourcing Agent | $10,000 订单对比表、18-35% 节省 | 数据来源不可验证、代理风险只字不提 |
| SourcingAll | 3-10% 佣金范围 | 全是通用知识，无个人经验 |
| SFA Commercial | 收费模式概述 | 引导"联系我们"获取报价 |

**共同特征**：教育包装 + 软推销 + 价格不透明 → 读者看完仍然不知道"到底要花多少钱"。

**你的机会**：做第一个说实话的人。

## 3. 搜索意图深度分析

搜"how much does a sourcing agent cost"的人，心理状态是：

**他们不是随便看看。他们已经：**
1. 确定要从中国采购产品
2. 听说过采购代理，或已被推荐
3. 正在考虑是否请代理帮他们
4. 在做预算，想知道这个成本加到总采购成本后划不划算

**他们的真实问题是（但没直接搜的）：**
- "我付了这笔钱，能省回来更多吗？"
- "会不会被骗？付了钱结果和不请代理一样？"
- "花$500请代理，和花$2,000请代理，差别在哪？"
- "是不是越贵的代理越好？"

**文章需要回答的核心问题：**
1. 到底多少钱？（直接回答）
2. 怎么收费？（模式清晰）
3. 值不值？（ROI 算清楚）
4. 怎么选？（给了判断框架）

## 5. 文章结构推荐（H1/H2/H3）

```
H1: How Much Does a China Sourcing Agent Cost? (Honest Numbers from Someone Who Does This)

H2: The Short Answer (Don't Make You Scroll)
  - 一句话总结：通常 $300-$2,000/项目 或 3%-10% 佣金
  - 一表格：快速参考（小订单 vs 大订单 vs 长期合作）

H2: How Sourcing Agents Actually Charge: 3 Fee Models
  H3: Commission-Based (Percentage of Order Value)
  H3: Fixed Project Fee (Per Product or Per Order)
  H3: Hybrid (Retainer + Lower Commission)
  - 每种模式的适用场景、优缺点、真实数字范围

H2: A Real Example: What a $5,000 Order Actually Costs
  - 用 Karsa 的真实订单做匿名化展示（产品名模糊，数字真实）
  - 列出每一项费用：产品价、代理费、验货、物流、关税
  - 对比：如果客户自己从阿里巴巴买会花多少

H2: What Affects the Cost? 5 Factors
  H3: Order Size (The Biggest Factor)
  H3: Product Complexity (Electronics vs. T-shirts)
  H3: Customization Level (OEM vs. Off-the-Shelf)
  H3: Number of Suppliers to Vet
  H3: QC Requirements

H2: Hidden Costs Nobody Talks About
  - 样品快递费（$30-80/次，多次迭代会累积）
  - 第三方检测费（CE/FCC 认证可能需要 $500-$3,000）
  - 模具费（定制产品的一次性投入）
  - 货币转换损失（PayPal/Wise 汇率差 1-3%）
  - 仓储费（如果你的货要在我们仓库暂存）

H2: Sourcing Agent vs. Alibaba vs. DIY: The Real Cost Comparison
  - 一个表格+文字说明
  - 关键洞察："Alibaba 免费"是个错觉
  - $30,000/年 采购额是分水岭

H2: Is a Sourcing Agent Worth the Cost? (Honest Answer: It Depends)
  H3: When an Agent Saves You MORE Than They Cost
  H3: When You Should Probably Go DIY
  - 给出一个自测清单（5 个问题）

H2: How We Charge at Youna Global (Transparent Breakdown)
  - Karsa 的真实收费模式
  - 明确说明什么情况下收多少
  - 不承诺"绝对最低价"
  - CTA: WhatsApp/Email 获取具体报价

H2: 5 Questions to Ask Before Hiring Any Sourcing Agent
  - 给买家一套面试问题（含标准答案的判断标准）
```
